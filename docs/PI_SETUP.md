# Raspberry Pi Deployment Guide

The trained `.pth` models generated by this repository can run on Raspberry Pi
4 or 5 using PyTorch CPU inference. The normal workflow is:

```text
PDF -> TXT -> JSON -> trained .pth model -> offline questions
```

The optional ExecuTorch/Llama engine described in older project material is a
separate engine and is not required for this model.

## Requirements

- Raspberry Pi 4 (4 GB+) or Raspberry Pi 5
- 64-bit Raspberry Pi OS
- Python 3.11 or 3.12, depending on the available ARM64 PyTorch wheel
- At least 4 GB RAM recommended for training; inference uses substantially less
- Internet only during setup; inference is offline

Install system packages:

```bash
sudo apt update
sudo apt install -y python3-dev python3-pip python3-venv tesseract-ocr
```

Create the environment:

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch
python -m pip install -r requirements.txt
```

If the selected Python version does not have a compatible ARM64 PyTorch wheel,
install a Raspberry Pi-compatible CPU PyTorch wheel first, then install the
remaining packages without replacing it:

```bash
python -m pip install --no-deps pypdf numpy spacy pymupdf pytesseract
```

## Copy and check a trained model

Copy the model produced on the development machine:

```bash
scp workstation:~/AI-for-Inclusive-Education-Offline-Smart-Learning-Assistant/models/demo_curriculum_model.pth models/
```

The checkpoint contains the vocabulary, model weights, knowledge chunks, and
precomputed embeddings. Use a model trained from the textbook data you want to
query.

## Run on Raspberry Pi

Interactive questions:

```bash
python train_and_qa.py interactive --model models/demo_curriculum_model.pth
```

Web GUI:

```bash
python gui.py
```

Uploaded PDFs are processed locally into a separate document folder:

```text
data/uploaded_documents/<document-id>/
  pdf/
  text/
  json/
models/uploaded_documents/<document-id>.pth
```

## Raspberry Pi expectations

| Device | Inference | Training |
|---|---|---|
| Raspberry Pi 5, 8 GB | Supported on CPU | Practical for smaller books |
| Raspberry Pi 4, 4 GB | Supported on CPU | Slow; train elsewhere when possible |

This project’s `EdgeNeuralQAModel` is a small Transformer retrieval model and
does not require CUDA, MPS, ExecuTorch, or cloud APIs. The application always
loads checkpoints with CPU mapping, so a model trained on macOS or another
machine can be queried on ARM64 when the Pi has a compatible PyTorch build.
