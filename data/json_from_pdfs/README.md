# JSON archives generated from PDFs

This folder is generated by:

```bash
./venv/bin/python train_and_qa.py convert-pdfs
```

The directory structure mirrors `pdfs_to_train/`. Each JSON file contains:

- PDF extraction statistics and warnings
- Page/chunk text with page references
- Grounded `what`, `how`, `when`, `where`, `who`, and `why` question/answer pairs

Do not edit these files manually. Add or replace PDFs in `pdfs_to_train/`, then run
the conversion command again.
